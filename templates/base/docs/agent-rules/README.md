# Agent rule guidance

These files are the detailed, reviewable source for the small entry points in
`.cursor/rules/`.

Read only the rule relevant to the current task:

- `project-architecture.md`: structure, feature folders and boundaries.
- `typescript-react.md`: TypeScript and React source changes.
- `styling.md`: TSX and CSS styling.
- `testing.md`: tests and validation strategy.
- `workflow.md`: bounded implementation workflow.

`AGENTS.md` remains the portable baseline. The `.cursor/rules/*.mdc` files are
Cursor discovery bridges, not a second source of truth.
